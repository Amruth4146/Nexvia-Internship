# Nexvia Technologies — Full-Stack Development Internship

This repository contains the two full-stack development projects completed as part of the Nexvia Technologies internship.

## Projects

### FS-01 — MarketSphere

A multi-vendor e-commerce marketplace where customers can purchase products from multiple vendors, vendors can manage their products and orders, and administrators can manage the platform.

**Key features**
- Customer, vendor and admin authentication.
- Vendor onboarding and product management.
- Product catalog, search and filtering.
- Shopping cart and checkout.
- Order and payment management.
- Vendor dashboards and admin analytics.
- Image uploads and secure image retrieval.

**Technology:** React, Vite, Node.js, Express, MongoDB, Mongoose, Redis, Razorpay and AWS S3.

**Live Demo:** https://market-sphere-tau.vercel.app

**Original Repository:** https://github.com/Amruth4146/MarketSphere

### FS-02 — CollabSpace

A real-time collaborative workspace that allows multiple users to work together on shared documents with live synchronization.

**Key features**
- User authentication and workspaces.
- Collaborative document editing.
- Real-time synchronization using Yjs.
- Live collaborator presence and cursors.
- Document sharing and permissions.
- Persistent document content.

**Technology:** React, TypeScript, Node.js, Express, Yjs, TipTap and WebSocket.

**Live Demo:** https://collab-space-smoky.vercel.app

**Original Repository:** https://github.com/Amruth4146/CollabSpace
